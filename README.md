# senmatic-movie-recommdender
A cross-platform movie recommendation app built with .NET MAUI frontend and a Python FastAPI backend. It provides movie suggestions based on keywords, categories, and emotional tone using semantic search and vector embeddings.

## Overview
A movie recommendation application built using Python and C#. The project uses semantic search and AI embeddings to recommend movies based on user preferences and natural language descriptions.

This was one of my first projects combining backend development, machine learning, and desktop application development.

## Technologies Used
- **Python** – Backend development and recommendation logic
- **C# / .NET MAUI** – Application interface
- **FastAPI** – REST API connecting the frontend and backend
- **LangChain** – Processing text and implementing semantic search
- **ChromaDB** – Vector database for movie embeddings
- **OpenAI Embeddings** – Understanding movie descriptions and user queries

## Features
- Natural language movie search
- AI-powered movie recommendations
- Semantic similarity matching
- Movie filtering by categories and emotional tone
- C# application connected to a Python backend through REST API

This is an early learning project that was successfully developed and tested locally. The application is not currently maintained, and additional configuration or adjustments may be required to run it.
